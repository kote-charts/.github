## Kote Charts — Bitcoin On-Chain Analytics API & MCP Server

110+ charts with history since 2009 — MVRV, NUPL, SOPR, exchange flows and whale analytics —
computed from our own Bitcoin full node, on [kotecharts.com](https://kotecharts.com).

- **MCP server for AI agents:** `https://kotecharts.com/api/v1/mcp` (no key) — `com.kotecharts/charts` in the official MCP Registry
- **REST API:** API key, 3 req/s — [docs](https://kotecharts.com/docs) · [OpenAPI](https://kotecharts.com/api/v1/openapi.json)
- **Machine-readable methodology:** [`/api/v1/metrics`](https://kotecharts.com/api/v1/metrics)
- **Verify it:** [status](https://kotecharts.com/status) · [changelog](https://kotecharts.com/changelog) · [public contract tests](https://github.com/kote-charts/kote-charts/actions/workflows/contract.yml)
- **SDKs & integrations:** [kote-charts/kote-charts](https://github.com/kote-charts/kote-charts) — `pip install kotecharts` · `npm i kotecharts`
